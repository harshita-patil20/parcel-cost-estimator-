Parcel Cost Estimator
Project Description 
The parcel cost estimator is a simple project that calculates the delivery cost of a parcel based on its weight and distance 

FEATURES
Enter parcel weight.
Enter delivery distance.
Calculate estimated parcel delivery cost.
Display the total cost.

TECHNOLOGY USED
python

HOW TO RUN
1.Download the project file.
2.Open it using python IDLE or VS Code.
Run The Program.
Enter the required details.
